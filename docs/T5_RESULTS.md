## 실행 중 고친 것

- 문장 분할: "2026. 4.~9." 같은 날짜의 마침표에서 문장이 잘림 → 숫자 뒤 마침표에서는 안 자름. △·>> 기호 제거.
- 조건 검사 오탐: "국립공원공단, …"의 "단,"을 조건 표시로 봄 → 한글 뒤 "단,"은 제외.
- 숫자 검사 오탐: "'26/'27년" ↔ "2026년, 2027년"을 불일치로 봄 → 'NN을 20NN으로 정규화.
- 보존 명칭 검사: 안 닫힌 「 가 다음 「…」까지 이어 붙음 → 괄호 안에 다른 여는 괄호가 오면 끊음.
- 위 세 가지로 통과가 875 → 885가 됐다(오탐 10건 해소). 규칙 변경 후 `python -m training.checks`로 다시 검사했다.

## 통과 짝의 한계 (사람이 무작위 20건을 읽어 본 결과)

자동 검사는 숫자·용어·대상·영어 단어만 보기 때문에 아래는 통과한다. 20건 중 약 5건(25%)에 문제가 있었다.
- 고유명사 훼손: "전남대병원" → "전라대학교병원"
- 정보 누락·뜻 변화: "표준데이터모델·표준통합운영체계와 AI 소프트웨어 시제품 공개" → "만드는 방법과 함께 AI 프로그램 시험 버전을 보여줍니다", "맞춤형 메뉴관리 기능 제공" → "원하는 메뉴를 직접 만들 수 있게"
- 형식: 한 문장을 여러 줄 목록과 덧붙인 맺음말로 바꿈. 출력이 여러 줄인 짝 20건 중 14건이 통과했다.
- 길이: 평균 원문 80자, 결과 91자로 오히려 길어진다(짧은 제목형 문장을 풀어 쓰는 경우).

다음 검사 후보(아직 구현 안 함): 출력 한 문단(줄바꿈 금지), 길이 비율 상한, 원문의 기관·병원명(…병원, …의료원, …센터, …공단) 보존, 교사 2개 교차 검증 또는 역질문. 그리고 T11의 사람 검수 200건으로 자동 검사의 오탐·누락 비율을 잰다.

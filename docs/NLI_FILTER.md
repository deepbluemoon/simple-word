# 학습 짝 뜻 검사 (NLI 필터)

통과 짝(`data/pairs.jsonl`에서 `passed=true`인 13,176개)의 원문과 쉬운 말이 같은 뜻인지 NLI 모델로 판정했다. `pairs.jsonl`은 그대로 두고, 판정 결과는 `data/nli.jsonl`(짝마다 `doc_id`, `idx`, 두 방향 확률, `flag`)에 따로 적는다. `data/`는 git에 올리지 않는다.

```
python -m training.nli --pairs data/pairs.jsonl --out data/nli.jsonl     # MPS 약 15분
python -m training.train --version v4 ... --nli data/nli.jsonl          # flag가 있는 짝을 train에서만 뺀다
```

`--nli`를 주면 train에서만 뺀다. valid·test는 그대로 두어 v3와 같은 문장으로 비교할 수 있다. 몇 개를 뺐는지는 `train_metrics.json`의 `nli`에 남는다. 아직 v4는 학습하지 않았다.

## 모델과 라이선스

- `MoritzLaurer/mDeBERTa-v3-base-xnli-multilingual-nli-2mil7`: 모델 카드 라이선스는 **MIT**이고 언어 태그에 `ko`가 있다. 학습 데이터 multilingual-NLI-26lang-2mil7에 한국어가 들어 있다. Mac(MPS)에서 배치 32로 13,176짝 × 두 방향을 약 15분에 돈다.
- 학습 데이터 중 ANLI는 CC BY-NC 4.0이다. 우리는 이 모델을 배포하거나 서비스에 넣지 않고, 학습 짝을 고르는 오프라인 판정에만 쓴다. 서비스 모델(KoBART)에도 이 모델의 가중치나 출력 문장은 들어가지 않는다.
- 교사 LLM(gemma3:27b)으로 판정하는 방법은 13k짝이면 몇 시간이 걸려 이번에는 쓰지 않았다. 아래처럼 정밀도가 낮으니, 걸린 338짝만 교사 LLM으로 다시 보는 2단계 방식을 다음 후보로 둔다.

## 판정 기준·임계값 (`training/nli.py`)

| 이유 | 조건 | 뜻 |
|---|---|---|
| contradiction | 정방향(src→tgt) 또는 역방향(tgt→src) 모순 확률 > **0.9** | 뜻이 바뀌거나 틀린 설명이 들어감 |
| omission | 역방향 함의 < **0.05** 이고 정방향 함의 < 0.5 | 쉬운 말에서 원문 내용이 나오지 않고, 원문도 쉬운 말을 뒷받침하지 않음(누락·지어낸 말) |

- 모순 임계값을 0.5로 두면 513짝(3.9%)이 걸리고, 그중 대부분은 표현만 바꾼 짝이었다. 300짝 시험에서 확인해 0.9로 올렸다. 0.7은 331짝, 0.95는 83짝이다.
- 쉬운 말은 원래 세부를 줄인다. 그래서 역방향 함의가 낮은 것만으로는 거르지 않고, 정방향 함의도 낮을 때만 거른다.

## 결과

| | 짝 | 비율 |
|---|---:|---:|
| 판정 | 13,176 | 100% |
| contradiction | 137 | 1.04% |
| omission | 201 | 1.53% |
| **걸러낼 짝** | **338** | **2.57%** |

## 예시 10개 (무작위로 뽑아 직접 판단)

| # | 이유 | 원문 (요약) | 쉬운 말 (요약) | 직접 판단 |
|---|---|---|---|---|
| 1 | contradiction (역 0.97) | 통합돌봄 전용 누리집은 … 핵심 정보 플랫폼 | 통합돌봄**(아이들을 돌보는 서비스)** 홈페이지는 … | **맞음**: 통합돌봄은 노인·장애인 돌봄이다 |
| 2 | contradiction (정 0.96) | 고액·상습 체납으로 인한 불공정 | 돈을 **많이 내지 않고** 자꾸 미루는 사람 | **맞음**: '고액 체납'을 잘못 풂 |
| 3 | omission | 제도가 현장에 안정적으로 정착되도록 민간전문가 자문으로 협업 강화 | 새로운 규칙이 **학교와** 잘 맞도록 … | **맞음**: 원문에 없는 '학교' |
| 4 | omission | ‘2026년 행정제도 개선 추진계획’을 수립하고 본격 시행 | … 이 계획을 **2026년부터** 실행합니다 | **맞음**(경계): 시행 시점을 지어냄 |
| 5 | omission | 상담사 교환교육을 마련 | 상담 선생님을 **바꿔서** 교육을 준비 | **맞음**(경계): '교환교육'을 잘못 풂 |
| 6 | contradiction (정 0.99) | 마약류 중독은 단속과 처벌만으로 해결하기 어렵다 | 마약에 빠지면 잡고 벌주는 것만으로는 해결하기 어렵다 | 틀림: 같은 뜻 |
| 7 | contradiction (역 0.96) | 7.16~20일 호우 피해 지역을 대통령 재가를 받아 특별재난지역으로 추가 선포 | … 특별재난지역으로 정했습니다. 대통령이 승인했습니다 | 틀림: 같은 뜻 |
| 8 | contradiction (정 0.93) | 그동안 질병 휴직을 활용해야 했지만 … 난임 휴직을 신청할 수 있다 | 예전에는 아플 때 쉬는 휴직을 썼어야 했지만 … | 틀림: 같은 뜻 |
| 9 | omission | 보건복지부 누리집 안내창을 통해서도 확인 가능 | 보건복지부 홈페이지에서도 볼 수 있습니다 | 틀림: 같은 뜻 |
| 10 | omission | 고유가 피해지원금 지급 준비를 위해 부단체장 회의 개최 | 기름값 때문에 힘든 사람들에게 주는 돈 … 모여서 준비를 확인 | 틀림: 같은 뜻 |

무작위로 본 14짝(위 10개 포함) 가운데 실제로 뜻이 틀리거나 지어낸 말이 있는 짝은 5개다. **정밀도는 약 35%로 낮다**. 걸린 짝의 3분의 2는 멀쩡한 짝이고, 특히 문장이 길거나 인용문을 다시 쓴 짝에서 모순으로 잘못 걸린다. 그래도 걸러낼 짝이 2.6%라 train 8,384짝에서 줄어드는 양은 작다. 진짜 오류 짝(약 120개로 추정)을 빼는 이득이 멀쩡한 짝 약 220개를 잃는 손해보다 큰지는 v4에서 `--nli`를 켜고 끈 두 모델을 비교해 정한다. 정밀도를 올리려면 걸린 338짝만 교사 LLM으로 다시 판정한다.

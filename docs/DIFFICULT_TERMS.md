## 사전 형태와 규칙

학습 도구는 `{어려운 말: {"alternatives": [쉬운 말...], "sources": [출처...]}}`를 사용한다. 국립국어원 이표기는 같은 대안어를 가진 별도 검색어로 넣고, 같은 어려운 말의 대안어와 출처는 중복 없이 합친다. 유니코드 NFC와 앞뒤 공백·인용부호를 정리한다. 한 글자 용어와 `가능`, `내용`, `대상`, `사항`처럼 지나치게 일반적인 용어는 제외한다. 서빙 모듈은 바꾸지 않았다.

국립국어원 원본은 기존처럼 자동으로 `data/nikl_terms.csv`에 받는다. 법제처 연계 응답은 `fetch_law_terms`가 `data/law_cache.jsonl`에 쌓는다(보관용 `data/law_terms.xml`도 읽는다). 하지만 교사·검사·평가가 쓰는 기본 사전에는 들어가지 않는다. `python -m training.terms --law raw|strict`처럼 명시할 때만 측정에 더한다. 원본 자료는 `.gitignore` 대상이며 커밋하지 않는다. 법제처 API는 `OC` 인증값을 요구하고 전체 용어 일괄 다운로드 경로/전체 건수를 공개하지 않아, 등록한 API 활용 범위에 따라 연계 응답을 보관해야 한다.

## 데이터 적용 범위

측정 코드는 다음 명령으로 실제 파일을 읽어 문장 포함률과 출처별 용어 적중 수를 낸다.

```bash
python -m training.terms --data data --pairs data/pairs.jsonl --candidates data/eval/candidates.jsonl
```

계수는 "용어-문장 출현" 기준이다. 한 문장에 여러 용어가 나오면 출처별 건수가 각각 늘어난다.

### 법제처 실제 호출 결과 (2026-11-20)

- **조회한 낱말:** 9,859개를 두 방향(법령용어→일상용어 `lstrmRlt`, 일상용어→법령용어 `dlytrmRlt`)으로 불렀다. 모두 19,718회이고, 캐시는 `data/law_cache.jsonl`(git에 안 올림)에 있다.
  - 평가셋 낱말(v1 후보 + 평가셋 v2, 1회 이상 나온 낱말)은 전부 조회했다.
  - 통과 짝 낱말은 3회 이상 나온 9,373개를 조회했다.
- **응답:** 결과가 있는 응답은 9,721건(lstrmRlt 4,866 / dlytrmRlt 4,855)이다. 나머지는 "일치하는 용어가 없습니다"였다.
- **시간 초과:** 지난번에 시간 초과로 멈췄던 조회는 남은 것만 이어 받았다. 네트워크 오류는 세 번 다시 시도한 뒤 건너뛴다.
- **동시 실행 사고:** 이전 세션의 조회 작업이 함께 돌아 같은 낱말을 두 번 받은 6,477쌍이 생겼다. 중복은 지웠다(첫 응답 유지). 이제 `fetch_law_terms`는 캐시 파일에 배타 잠금을 걸고, 다른 조회가 돌고 있으면 `LawFetchBusy`로 멈춘다.

**사전 크기와 포함률**(`python -m training.terms --data data --pairs data/pairs.jsonl --candidates data/eval/eval_set.jsonl [--law raw|strict]`):

| 사전 | 국립국어원 용어 | 법제처 용어 | 통과 짝 13,176 중 용어 있는 문장 | 평가셋 v2 200 중 | 법제처 적중(통과 짝 / 평가셋) |
|---|---:|---:|---:|---:|---:|
| 국립국어원만(기본, 교사·검사·평가가 씀) | 1,627 | — | 219 (**1.7%**) | 19 (**9.5%**) | — |
| + 법제처 동의어 전부(`--law raw`) | 1,627 | 3,728 | 12,981 (98.5%) | 194 (97.0%) | 75,990 / 1,086 |
| + 법제처 엄격(`--law strict`) | 1,627 | 209 | 3,288 (25.0%) | 68 (34.0%) | 3,629 / 63 |

국립국어원 적중은 통과 짝 232건, 평가셋 20건이다(세 경우 같음).

### 판단: 법제처 동의어는 어려운 용어 사전으로 쓰지 않는다

- **raw:** 법제처 '동의어'는 양방향 동의어라 어려운 말→쉬운 말이 아니다(지원→뒷바라지, 국민→내국인, 계획→플랜). 거의 모든 문장(98.5%)에 걸려 '어려운 용어 유지율' 같은 지표가 뜻을 잃는다.
- **strict:** 법령용어→일상용어 방향만 쓰고, 일상용어로도 등록된 법령용어는 빼고, 한글 대안어만 남긴 사전이다. 그래도 많이 걸리는 말 대부분이 어려운 말이 아니다.
  - 통과 짝에서 많이 나온 순: 지난(434)→지나간, 특히(381)→특별히, 모든(147)→다, 대구(98)→대구광역시, 만들기(30)→제작
  - 대안어가 오히려 어렵거나 틀린 경우: 간담회(212)→정담회, 의료진(66)→진료진, 초등(38)→초급, 도출(33)→산출, 마주(18)→경주마소유자
  - 쓸 만한 것은 일부다: 향후(179)→앞으로, 제고(63)→높임, 최우선(54)→가장 먼저, 직결(21)→연결, 각국(21)→각 나라, 당일(19)→그날
- **결정:**
  - 교사 프롬프트·검사·평가(`nikl_dict`)는 지금처럼 국립국어원만 쓴다.
  - 법제처 strict 209개는 사람(또는 Claude)이 골라 쓸 **후보 목록**으로만 둔다. 고른 용어를 따로 파일로 만들어 사전에 더하는 것은 다음 작업이다.
  - 국립국어원 사전은 통과 짝의 1.7%에만 걸린다. 그래서 어려운 용어 지표가 보는 문장이 적다(평가셋 v2에서 n=20). 이 점은 평가 해석에 계속 적어 둔다.

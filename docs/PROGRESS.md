# simple-word 작업 기록

시간 표시는 생략하고 작업 순서로 정리한다.

## 1차 완료 기준

- v0.1 태그를 기준으로 1차 작업을 마쳤다. 태그의 기준 커밋은 `33fe9b6`이다.

## 2차 작업 진행

- 문서·운영·학습·프론트엔드 기능을 병렬로 보완하기 시작했다. 프론트엔드는 원문과 변경점 비교, 숫자 보존 강조, 원문 유지 사유, 읽기 설정, 내보내기, 재시도 상태와 접근성을 다루었다.
- 배포 준비는 클라우드 계정 없이 로컬 compose에서 배포·롤백·카나리 절차를 검증하도록 분리했다.
- 모델 학습에는 데이터 누수 검사, 시간순 분할, early stopping, 후보 게이트를 포함하는 방향을 정리했다.
- 운영 문서에는 비용, 포트, CI, 충돌 처리와 배포 준비를 정리했다.
- 어려운 용어 출처를 조사했다. 이용허락이 명확한 기존 국립국어원 목록과 법제처 연계 API만 사전 대상으로 두고, 라이선스가 불분명하거나 공공누리 제4유형인 목록은 제외했다.
- 학습 측 사전을 출처와 대안어를 보존하는 형태로 통합하고, 프롬프트·짝 검사·평가셋 분류·유지율 지표가 함께 사용하도록 변경했다. 서빙 코드는 변경하지 않았다.
- 데이터 커버리지 측정 기능과 테스트를 추가했다. 이 작업 환경에는 gitignored `data/` 입력이 없어 2,053 통과 짝과 200 평가 후보의 수치를 산출하지 못했다. 입력 복구 후 `docs/DIFFICULT_TERMS.md`의 명령으로 계산한다.

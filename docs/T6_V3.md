## v3 선택: v3-base

- 사람이 검수한 평가셋에서 v3-ph는 SARI(0.3835)·BERTScore(0.8081)·어려운 용어 유지율(0.68)이 셋 중 가장 나쁘다. 공정 test에서의 SARI·어려운 용어 우위는 평가셋에서 재현되지 않았다.
- v3-ph의 조사 오류는 복원 때문에 생긴다. 자리표시자 앞뒤 조사를 원래 낱말 받침에 맞추지 않아 "건강보험**를**", "기초연금**를**", "장기요양**와**" 같은 출력이 나온다. 다시 시도하려면 복원할 때 조사 교정(을/를·이/가·은/는·와/과·으로/로)이 먼저 필요하다.
- v3-base는 평가셋 SARI·길이·어려운 용어·fallback·속도가 v2 이상이다. BERTScore만 낮다.

## 게이트: `run_gate("v2", "v3-base")` → **FAIL**

`models/*/metadata.json`의 v2 지표는 v2 자체 test(186문장) 값이고 v3-base metadata에는 평가 지표가 없다. 그래서 같은 문장 기준으로 비교하려고, 두 모델의 metrics만 같은 세트 평가값으로 바꾼 임시 models 디렉터리(ONNX·parity는 실제 파일 링크)에서 게이트를 돌렸다.

| 기준 세트 | 결과 | 사유 |
|---|---|---|
| 평가셋 193 | FAIL | bert_score 0.8229 < champion 0.8348 |
| 공정 test 1,204 | FAIL | bert_score 0.8260 < champion 0.8431 |

나머지 조건(숫자·보존 용어 1.0, 길이 ≥ champion, 어려운 용어 ≤ champion, SARI > champion, p95 ≤ 1000ms, 메모리 ≤ 300MB, parity 0건)은 통과했다. 게이트를 통과하지 못해 `register_candidate`는 실행하지 않았고 `models/registry.json`의 champion(v2)도 그대로다. 보고서는 `reports/v3/gate-evalset/`, `reports/v3/gate-fair/`.
